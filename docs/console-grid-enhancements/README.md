# 数据网格与资源树交互

## 数据网格

- 表数据和控制台结果共用网格渲染模块，列宽按内容估算并设置上限。
- 表头右侧支持拖拽调整列宽，宽度在当前标签页内保持。
- 表数据支持多字段组合排序：升序 → 降序 → 取消，工具栏显示并可单独移除排序条件。
- 表数据分页展示精确总条数、总页数和本页条数，并按页码边界控制首页、上一页、下一页和末页按钮。
- 普通点击单元格或行号选中一行；`Shift+点击` 按固定起点连续选择，可反向选择或缩小区间；`Ctrl+点击` 逐行追加或取消；`Ctrl+Shift+点击` 追加一个连续区间。
- 鼠标移出及切换标签后保留选中集合，状态栏显示多选数量；刷新数据或换页后清除选择与 Shift 起点，表标签和各控制台结果分别保存状态。
- 单个单元格选中时，`Ctrl+C` 复制完整值，`NULL` 复制为空字符串；多行或行号选择时，复制为不含列名的 TSV，方便粘贴到表格。输入框与原生文本选区使用原有复制行为。
- 右键已选行保留多选集合，右键未选行改为单选；可复制为 JSON、INSERT、CSV 或 TSV，按当前页显示顺序复制完整原始值。
- JSON 单行返回对象、多行返回对象数组；CSV/TSV 的右键复制只附带一次列名；多行 INSERT 每行生成一条语句。
- 数据表的 INSERT 使用当前数据库和表名；控制台结果通过弹窗填写目标表，SQL 方言和默认模式使用该结果执行时的上下文。JSON/INSERT 遇到重复列名会明确报错，需要为查询列设置不同别名；CSV/TSV 保留重复列。
- 右键行号或单元格可冻结当前页从首行到所选行；右键表头或单元格可冻结从首列到所选列。行列可以同时冻结，支持分别取消或全部取消；冻结设置按表标签及结果页签独立保存，换页和拖动列宽后继续生效。
- 表数据与控制台结果均支持 CSV 导出。

每次加载或刷新表数据时都会额外执行一条 `COUNT(*)`，复用当前表和 WHERE 条件，但不包含排序、`LIMIT` 或 `OFFSET`。大表、缺少合适索引或条件复杂时，COUNT 可能带来额外数据库负载；总数查询失败会显式展示错误，不把 `/query/` 的 `affected_rows` 当作总条数。

## 筛选与表浏览

- WHERE 工具栏接受条件片段，例如 `status = 1 AND name LIKE 'A%'`，并提供当前表字段、关键词和数据库方言函数联想。
- 单击表节点直接打开数据浏览；点击左侧箭头展开列、键和索引。
- 表和列的悬浮提示展示类型与注释；表结构按需请求并缓存。
- MySQL 资源层级为“实例 → 数据库 → 表”，PostgreSQL 为“实例 → 数据库 → 模式 → 表”。
- MySQL 结构视图从 `CREATE TABLE` 解析字符串、数字、`NULL` 和 `CURRENT_TIMESTAMP[(精度)]` 等默认值；DDL 高亮将反引号/双引号标识符作为原子 token，避免 HTML 污染。

## 树与控制台联动

- 控制台切换实例、数据库或 PostgreSQL 模式时，左侧树自动展开并高亮对应节点。
- 展开或收起树上的数据库、模式节点只影响资源浏览，不覆盖当前控制台的实例、数据库和模式上下文。
- 右键实例、数据库或模式节点并选择“在当前控制台打开”，才会显式覆盖当前控制台上下文。
- 打开数据表会进入独立的表标签；从表标签新建控制台时继承该表的实例、数据库和模式。
- 新建控制台继承当前表标签或最近一次树选择的实例、数据库和模式。
- 跨 schema 同名表使用独立标签和元数据上下文，不会互相覆盖。
- 右键搜索结果中的数据库或表并选择“定位”，会清空搜索、展开所属路径并高亮目标节点。

## 代码结构

| 模块 | 职责 |
|------|------|
| `grid.mjs` | 网格 HTML、列宽计算、转义 |
| `grid-interactions.mjs` / `grid-state.mjs` | 网格交互编排、表与结果页签的选择和冻结状态 |
| `grid-selection.mjs` | 不可变的行集合、Shift 起点、修饰键规则与选择状态文案 |
| `grid-layout.mjs` / `grid-menu.mjs` | 冻结偏移、层级与右键菜单 |
| `row-copy.mjs` / `row-copy-actions.mjs` | 多格式行序列化、剪贴板写入与控制台 INSERT 目标表弹窗 |
| `resource-tree-view.mjs` | MySQL/PostgreSQL 资源树渲染 |
| `ddl.js` / `table-view.mjs` | MySQL CREATE TABLE / PostgreSQL 列元数据解析，以及数据、结构和 DDL 子视图 |
| `app-events.mjs` | 点击、输入、快捷键、拖拽和悬浮事件绑定 |
| `db-context.mjs` | 数据库类型、schema 上下文、分页查询和 COUNT SQL 生成 |

SQL 自动联想的完整规则见 [SQL 自动联想增强](../sql-autocomplete-enhancements/)。

## 验证

- 自动化验证与手工验证应覆盖空表、总数恰好为页大小整数倍、筛选后总数变化、末页边界和 PostgreSQL schema COUNT。
- `test/e2e.js` 提供 MySQL 表数据/结构/DDL、PostgreSQL schema 表数据/结构、排序筛选相关基础链路。
- `test/row-copy.mjs` 和 `test/grid-state.mjs` 覆盖修饰键选择、不可变集合、单行/多行序列化、剪贴板失败、状态隔离、分页与冻结重置，纳入 `npm test`。
- `test/grid-browser.py` 使用固定测试数据运行生产网格渲染器和事件委托，验证 Shift/Ctrl 多选、右键保留集合、真实批量剪贴板、冻结滚动、列宽调整、结果切换、空结果和弹窗复制快照。运行方式见[测试指南](../testing.md#网格浏览器交互测试)。
