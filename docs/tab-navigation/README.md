# 工作区标签导航

面向同时查看多张表、在查询控制台之间切换的桌面工作区。标签保持单行，表名和数据库分两行显示，数据表格的可用高度保持稳定。

## 视觉方案

沿用 SQL Studio 的主题变量和数据库图标颜色。

| 角色 | 浅色主题 | 用途 |
|------|----------|------|
| 内容面板 | `#ffffff` | 当前标签和标签列表 |
| 标签栏底色 | `#f8fafc` | 未选中的标签背景 |
| 分隔线 | `#d8dee8` | 标签与工作区边界 |
| 主要文字 | `#1f2937` | 表名和控制台名称 |
| 次要文字 | `#596579` | 数据库、schema 和实例 |
| 当前项强调 | `#3574f0` | 当前标签标记、焦点和选中状态 |

字体沿用 `--ui`（Segoe UI / Microsoft YaHei UI），名称 12.5px，数据源 11px。内容左对齐，关闭按钮固定在右侧。深色主题使用现有语义变量。

```text
[新建查询] [表图标 表名        ×] [控制台图标 查询名称 ×] ... [‹ ›] [列表 数量]
           数据库.schema         数据库.schema
```

布局取舍：标签整体保持单行，内部用两行文字区分名称与数据源。宽度有界，长名称以省略号显示，悬停可查看完整路径。大量标签通过横向浏览和搜索定位，避免换行挤占结果区。

## 操作

- 鼠标滚轮或触控板横向浏览；溢出时显示左右翻页按钮。
- 新开或切换标签时自动显示当前项；普通重绘保留手动滚动位置。
- 右侧列表按钮显示已打开的标签数量，支持按名称、数据库、schema、实例搜索；多个关键词用空格分隔。
- 列表只显示已打开标签，控制台关闭后的保存和重开行为沿用原有逻辑。
- 标签获得焦点后，可用左右方向键、Home、End 切换，Delete 关闭。
- 搜索框内用上下方向键选择、Enter 切换、Escape 关闭列表。
- 标签右键菜单继续提供关闭、关闭其他、关闭右侧和全部关闭。
